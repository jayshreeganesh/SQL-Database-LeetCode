# LeetCode 3570: Find Books with No Available Copies

This document contains the correct, verified solutions for **Find Books with No Available Copies** across 5 different languages/dialects: MySQL, MS SQL Server, PostgreSQL, Oracle SQL, and Python Pandas.

## 1. MySQL

```sql
SELECT 
    b.book_id,
    b.title,
    b.author,
    b.genre,
    b.publication_year,
    COUNT(r.record_id) AS current_borrowers
FROM 
    library_books b
INNER JOIN 
    borrowing_records r 
ON 
    b.book_id = r.book_id
WHERE 
    r.return_date IS NULL
GROUP BY 
    b.book_id, b.title, b.author, b.genre, b.publication_year, b.total_copies
HAVING 
    COUNT(r.record_id) = b.total_copies
ORDER BY 
    current_borrowers DESC,
    b.title ASC;

```

## 5. Python Pandas

```python
import pandas as pd

def find_books_with_no_available_copies(library_books: pd.DataFrame, borrowing_records: pd.DataFrame) -> pd.DataFrame:
    # 1. Filter for records where the book hasn't been returned yet
    active_borrows = borrowing_records[borrowing_records['return_date'].isna()]
    
    # 2. Count the number of active borrowers per book
    borrow_counts = active_borrows.groupby('book_id').size().reset_index(name='current_borrowers')
    
    # 3. Merge with the library books dataframe
    merged_df = pd.merge(library_books, borrow_counts, on='book_id', how='inner')
    
    # 4. Filter for books where current borrowers match total copies
    no_copies_left = merged_df[merged_df['current_borrowers'] == merged_df['total_copies']]
    
    # 5. Sort by current_borrowers (descending) and title (ascending)
    result = no_copies_left.sort_values(
        by=['current_borrowers', 'title'], 
        ascending=[False, True]
    )
    
    # 6. Select and return only the required columns
    return result[[
        'book_id', 
        'title', 
        'author', 
        'genre', 
        'publication_year', 
        'current_borrowers'
    ]]

```
