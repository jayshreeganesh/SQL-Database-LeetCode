## 1. MySQL

This approach uses a clean `CASE WHEN` statement. We handle the potential three-valued logic trap by filtering out `NULL` values in the subquery.

```sql
SELECT 
    id,
    CASE 
        WHEN p_id IS NULL THEN 'Root'
        WHEN id IN (SELECT DISTINCT p_id FROM Tree WHERE p_id IS NOT NULL) THEN 'Inner'
        ELSE 'Leaf'
    END AS type
FROM 
    Tree;

```

## 5. Python (Pandas)

Instead of using a slow row-by-row `.apply()`, this approach uses NumPy's vectorized `np.select()` to assign values across the DataFrame at lightning speed.

```python
import pandas as pd
import numpy as np

def tree_node(tree: pd.DataFrame) -> pd.DataFrame:
    # 1. Define our conditional masks (the "WHEN" clauses)
    is_root = tree['p_id'].isna()
    
    # .dropna() mimics the SQL 'WHERE p_id IS NOT NULL' to handle nulls safely
    is_inner = tree['id'].isin(tree['p_id'].dropna())
    
    # 2. Set up the conditions and corresponding choices (the "THEN" clauses)
    conditions = [
        is_root,
        is_inner
    ]
    choices = ['Root', 'Inner']
    
    # 3. Apply choices, defaulting to 'Leaf' (the "ELSE" clause)
    tree['type'] = np.select(conditions, choices, default='Leaf')
    
    # Return only the required columns
    return tree[['id', 'type']]

```
