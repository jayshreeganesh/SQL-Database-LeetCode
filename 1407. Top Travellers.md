# LeetCode 1407: Top Travellers

## 1. MySQL Solution
```sql
SELECT 
    u.name, 
    IFNULL(SUM(r.distance), 0) AS travelled_distance
FROM 
    Users u
LEFT JOIN 
    Rides r ON u.id = r.user_id
GROUP BY 
    u.id, 
    u.name
ORDER BY 
    travelled_distance DESC, 
    u.name ASC;

```

## 5. Pandas Solution (Python)

```python
import pandas as pd

def top_travellers(users: pd.DataFrame, rides: pd.DataFrame) -> pd.DataFrame:
    # 1. Rename 'id' to 'user_id' in users to prevent duplicate column KeyError flags
    users = users.rename(columns={'id': 'user_id'})
    
    # 2. Left join users and rides on 'user_id'
    merged_df = pd.merge(users, rides, on='user_id', how='left')
    
    # 3. Group by 'user_id' and 'name', then sum the distances
    grouped = merged_df.groupby(['user_id', 'name'])['distance'].sum().reset_index()
    
    # 4. Fill NaN values with 0 for users who took no rides
    grouped['travelled_distance'] = grouped['distance'].fillna(0).astype(int)
    
    # 5. Sort by travelled_distance (descending) and name (ascending)
    result = grouped.sort_values(
        by=['travelled_distance', 'name'], 
        ascending=[False, True]
    )
    
    # 6. Return only the required columns
    return result[['name', 'travelled_distance']]

```

## Key Takeaways across Dialects:

| Dialect | Null Handling Function | Group By Trap |
| --- | --- | --- |
| **MySQL** | `IFNULL()` | Flexible, but standard grouping is highly recommended. |
| **MS SQL Server** | `ISNULL()` | Strict; all unaggregated SELECT columns must be in `GROUP BY`. |
| **PostgreSQL** | `COALESCE()` | Strict; standard ANSI rules apply. |
| **Oracle** | `NVL()` | Strict; explicit groupings and ordering matching required. |
| **Pandas** | `.fillna(0)` | Requires tracking column modifications (e.g. `id` to `user_id`) to avoid `KeyError` conflicts. |
