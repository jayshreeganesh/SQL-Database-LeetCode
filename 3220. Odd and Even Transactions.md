# LeetCode 3220: Odd and Even Transactions

## Problem Description
Write a solution to find the **sum of amounts** for **odd** and **even** transactions for each day. If there are no odd or even transactions for a specific date, display as `0`.

Return the result table ordered by `transaction_date` in **ascending** order.

---

## 1. MySQL Solution
Uses conditional aggregation with the native `IF()` function.

```sql
SELECT 
    transaction_date,
    SUM(IF(amount % 2 != 0, amount, 0)) AS odd_sum,
    SUM(IF(amount % 2 = 0, amount, 0)) AS even_sum
FROM 
    transactions
GROUP BY 
    transaction_date
ORDER BY 
    transaction_date ASC;

```

---

## 2. MS SQL Server Solution

Uses standard ANSI `CASE WHEN` statements since T-SQL does not support `IF()` inline aggregates.

```sql
SELECT 
    transaction_date,
    SUM(CASE WHEN amount % 2 != 0 THEN amount ELSE 0 END) AS odd_sum,
    SUM(CASE WHEN amount % 2 = 0 THEN amount ELSE 0 END) AS even_sum
FROM 
    transactions
GROUP BY 
    transaction_date
ORDER BY 
    transaction_date ASC;

```

## 3. PostgreSQL Solution

Features the highly clean and optimized native `FILTER` clause.

```sql
SELECT 
    transaction_date,
    COALESCE(SUM(amount) FILTER (WHERE amount % 2 != 0), 0) AS odd_sum,
    COALESCE(SUM(amount) FILTER (WHERE amount % 2 = 0), 0) AS even_sum
FROM 
    transactions
GROUP BY 
    transaction_date
ORDER BY 
    transaction_date ASC;

```

## 4. Oracle SQL Solution

Requires explicit date-to-string formatting using `TO_CHAR()` to remove default timestamps (`00:00:00`) and uses the `MOD()` function.

```sql
SELECT 
    TO_CHAR(transaction_date, 'YYYY-MM-DD') AS transaction_date,
    SUM(CASE WHEN MOD(amount, 2) != 0 THEN amount ELSE 0 END) AS odd_sum,
    SUM(CASE WHEN MOD(amount, 2) = 0 THEN amount ELSE 0 END) AS even_sum
FROM 
    transactions
GROUP BY 
    TO_CHAR(transaction_date, 'YYYY-MM-DD')
ORDER BY 
    transaction_date ASC;

```

## 5. Pandas Solution (Python)

An elegant pivoting approach using a calculated flag column, `unstack()`, and `reindex()` to automatically handle missing categorical balances.

```python
import pandas as pd

def sum_daily_odd_even(transactions: pd.DataFrame) -> pd.DataFrame:
    # Format date to match standard output structure
    transactions['transaction_date'] = pd.to_datetime(transactions['transaction_date']).dt.strftime('%Y-%m-%d')
    
    # Map each row to its column categorization
    transactions['type'] = transactions['amount'].apply(lambda x: 'odd_sum' if x % 2 != 0 else 'even_sum')
    
    # Pivot rows into explicit aggregate sum columns
    result = transactions.groupby(['transaction_date', 'type'])['amount'].sum().unstack(fill_value=0).reset_index()
    
    # Guarantee structural layout even if an entire type category is missing
    result = result.reindex(columns=['transaction_date', 'odd_sum', 'even_sum'], fill_value=0)
    
    return result.sort_values(by='transaction_date').reset_index(drop=True)

```
