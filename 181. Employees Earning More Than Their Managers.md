# LeetCode 181: Employees Earning More Than Their Managers

## Problem Description
Find the employees who earn more than their managers. An employee's manager is identified by their `managerId`, which corresponds to the `id` of another employee in the same table.

### Input Table: `Employee`
| Column Name | Type    |
|-------------|---------|
| id          | int     |
| name        | varchar |
| salary      | int     |
| managerId   | int     |

### Expected Output
| Employee |
|----------|
| Joe      |

---

## Solutions

### 1. MySQL
Standard ANSI SQL self-join approach.
```sql
SELECT 
    e.name AS Employee
FROM 
    Employee e
INNER JOIN 
    Employee m ON e.managerId = m.id
WHERE 
    e.salary > m.salary;

```

### 5. Pandas (Python)

Achieved via a self-merge on the dataframe, filtering rows, and renaming the result column.

```python
import pandas as pd

def find_employees(employee: pd.DataFrame) -> pd.DataFrame:
    # 1. Self-merge: join employee with itself on managerId = id
    merged_df = employee.merge(
        employee, 
        left_on='managerId', 
        right_on='id', 
        suffixes=('_emp', '_mgr')
    )
    
    # 2. Filter rows where employee's salary is greater than manager's salary
    result_df = merged_df[merged_df['salary_emp'] > merged_df['salary_mgr']]
    
    # 3. Select only the employee's name column and rename it to 'Employee'
    return result_df[['name_emp']].rename(columns={'name_emp': 'Employee'})

```

* **Pandas Approach:** Uses vectorization via `.merge()` and boolean indexing, removing the need for slow Python loops.
