# LeetCode Solution: Find COVID Recovery Patients

## Problem Overview & Logic

The goal is to calculate the recovery time for each patient. Recovery time is defined as the number of days between a patient's **first positive test date** and their **subsequent first negative test date**.

### ⚠️ Crucial Edge Case

A patient may have taken routine routine negative tests *before* ever testing positive (e.g., Carol Davis). The logic must strictly look for the first negative test whose date is **strictly greater** than the earliest positive test date.

---

## 1. MySQL 8.0 Solutions

### Approach A: Common Table Expressions (CTEs) & Aggregation (Recommended)

This approach splits the problem into modular, easily maintainable logic steps using `WITH` clauses and standard aggregation (`MIN`).

```sql
WITH FirstPositive AS (
    -- Step 1: Find the earliest positive test date for each patient
    SELECT 
        patient_id, 
        MIN(test_date) AS first_pos_date
    FROM covid_tests
    WHERE result = 'Positive'
    GROUP BY patient_id
),
FirstNegativeAfter AS (
    -- Step 2: Find the first negative test date that occurs AFTER the first positive test
    SELECT 
        fp.patient_id,
        fp.first_pos_date,
        MIN(ct.test_date) AS first_neg_date
    FROM FirstPositive fp
    JOIN covid_tests ct 
      ON fp.patient_id = ct.patient_id 
     AND ct.result = 'Negative' 
     AND ct.test_date > fp.first_pos_date
    GROUP BY fp.patient_id, fp.first_pos_date
)
-- Step 3: Join with the patients table to get metadata and calculate recovery time
SELECT 
    p.patient_id,
    p.patient_name,
    p.age,
    DATEDIFF(fn.first_neg_date, fn.first_pos_date) AS recovery_time
FROM FirstNegativeAfter fn
JOIN patients p 
  ON fn.patient_id = p.patient_id
ORDER BY 
    recovery_time ASC, 
    p.patient_name ASC;

```

#### Line-by-Line Explanation:

* **Lines 1–8 (`FirstPositive`):** Creates a temporary result layer filtering out only `'Positive'` tests. It groups by `patient_id` and uses `MIN(test_date)` to determine the precise baseline infection day.
* **Lines 9–20 (`FirstNegativeAfter`):** Joins our positive base table back to the raw `covid_tests` log (`ct`). It explicitly isolates records where `result = 'Negative'` and forces `ct.test_date > fp.first_pos_date` to flush out any pre-infection tests. Grouping ensures we extract only the closest sequential negative step using `MIN(ct.test_date)`.
* **Lines 22–32 (Final Select):** Gathers the clean date frames and joins to the descriptive `patients` metadata table.
* **Line 26:** `DATEDIFF(end_date, start_date)` measures the absolute day count interval.
* **Lines 30–32:** Sorts ascending by duration length, using alphabetical names to break ties.

## 5. Python 3.10 / Pandas 2.2.2 / NumPy 1.26.4 Solution

### Approach: Vectorized Filtering and Vector Math

```python
import pandas as pd
import numpy as np

def find_covid_recovery_patients(patients: pd.DataFrame, covid_tests: pd.DataFrame) -> pd.DataFrame:
    # Line 1: Cast object/string columns to true datetime64 types
    covid_tests['test_date'] = pd.to_datetime(covid_tests['test_date'])
    
    # Line 2: Extract rows matching positive confirmations
    pos_tests = covid_tests[covid_tests['result'] == 'Positive']
    if pos_tests.empty:
        return pd.DataFrame(columns=['patient_id', 'patient_name', 'age', 'recovery_time'])
        
    # Line 3: Isolate earliest positive instances via grouping
    first_pos = pos_tests.groupby('patient_id')['test_date'].min().reset_index(name='first_pos_date')
    
    # Line 4: Isolate independent negative confirmations
    neg_tests = covid_tests[covid_tests['result'] == 'Negative']
    
    # Line 5: Merge matching keys to line up timeline trajectories
    merged = pd.merge(neg_tests, first_pos, on='patient_id')
    
    # Line 6: Apply cross-column scalar logical filter (ignoring pre-infection tests)
    valid_neg = merged[merged['test_date'] > merged['first_pos_date']]
    
    # Line 7: Compute minimal post-infection clearance dates
    first_neg = valid_neg.groupby(['patient_id', 'first_pos_date'])['test_date'].min().reset_index(name='first_neg_date')
    
    # Line 8: Run vectorized arithmetic and read continuous integer day durations
    first_neg['recovery_time'] = (first_neg['first_neg_date'] - first_neg['first_pos_date']).dt.days
    
    # Line 9: Structural identity merge for human-readable output
    result = pd.merge(first_neg[['patient_id', 'recovery_time']], patients, on='patient_id')
    
    # Line 10: Format final column tracking schema and sort keys
    result = result[['patient_id', 'patient_name', 'age', 'recovery_time']]
    result = result.sort_values(by=['recovery_time', 'patient_name'], ascending=[True, True])
    
    return result

```

#### Line-by-Line Explanation:

* **Line 5:** `pd.to_datetime()` converts raw string objects into structured pandas `datetime64[ns]` formats. Without this step, trying to compute date arithmetic will crash with a `TypeError`.
* **Lines 8–12:** Isolates the rows where `result == 'Positive'` and groups them by `patient_id`. Calling `.min()` instantly locates the baseline infection date for each patient.
* **Lines 14–18:** Isolates negative tests and merges them with the `first_pos` table by `patient_id`, creating a working combined layout.
* **Line 21:** Drops any negative rows that don't satisfy the strictly later criteria (`merged['test_date'] > merged['first_pos_date']`).
* **Line 24:** Re-groups the valid rows to narrow down the earliest subsequent negative clearance date per patient.
* **Line 27:** Directly subtracts the series objects. Because they are true datetimes, this operation outputs a `timedelta64[ns]` object. Appending the vector accessor `.dt.days` instantly extracts clean integers.
* **Lines 30–34:** Joins the patient profiles, strips intermediate tracking metrics, and sorts the final structure to match the output requirements.
