# LeetCode 182: Duplicate Emails (Multi-Language Solutions)

A collection of accepted solutions for LeetCode 182 using MySQL, MS SQL Server, PostgreSQL, Oracle, and Python (Pandas).

---

## 1. MySQL
### Approach: `GROUP BY` and `HAVING`
Standard, efficient query grouping identical rows together and filtering groups with a count greater than 1.

```sql
SELECT email AS Email
FROM Person
GROUP BY email
HAVING COUNT(email) > 1;

```

---

## 2. MS SQL Server

### Approach: Common Table Expression (CTE) & `ROW_NUMBER()`

While `GROUP BY` works perfectly here, using a window function is incredibly useful in SQL Server if you ever need to scale the query to delete duplicates later.

```sql
WITH PartitionedEmails AS (
    SELECT email,
           ROW_NUMBER() OVER(PARTITION BY email ORDER BY id) AS row_num
    FROM Person
)
SELECT DISTINCT email AS Email
FROM PartitionedEmails
WHERE row_num > 1;

```

---

## 3. PostgreSQL

### Approach: Case-Preserved `GROUP BY`

PostgreSQL handles standard ANSI SQL beautifully. Note the double quotes `AS "Email"` used to strictly preserve the exact casing expected by LeetCode.

```sql
SELECT email AS "Email"
FROM Person
GROUP BY email
HAVING COUNT(email) > 1;

```

---

## 4. Oracle SQL

### Approach: Window Subquery

Oracle converts standard aliases to UPPERCASE by default. To match the expected camel-case format, we enforce the alias with double quotes. This version captures the second instance of any repeating email.

```sql
SELECT email AS "Email"
FROM (
    SELECT email,
           ROW_NUMBER() OVER (PARTITION BY email ORDER BY id) AS rn
    FROM Person
)
WHERE rn = 2;

```

## 5. Python (Pandas)

### Approach: Vectorized `duplicated()` Filter

The most Pythonic and optimal way to extract duplicates in Pandas using highly optimized vectorized operations.

```python
import pandas as pd

def duplicate_emails(person: pd.DataFrame) -> pd.DataFrame:
    # Find rows where the email has appeared before
    duplicates = person[person.duplicated(subset=['email'])]
    
    # Isolate email column, remove redundancies, and rename
    return duplicates[['email']].drop_duplicates().rename(columns={'email': 'Email'})

```
