# Fuel Efficiency Improvement Tracker: Multi-Language Implementation Guide

This document provides detailed, high-precision implementations to calculate and identify drivers with improved fuel efficiency between the first half (Months 1–6) and second half (Months 7–12) of the year. 

To prevent intermediate precision loss or truncation errors, calculations preserve full decimal and floating-point accuracy during aggregation steps. Final values are formatted and rounded to exactly 2 decimal places at the terminal selection step.

---

## 1. MySQL 8.0 Implementation

### Solution Code
```sql
WITH trip_efficiencies AS (
    SELECT 
        driver_id,
        distance_km / fuel_consumed AS efficiency,
        MONTH(trip_date) AS trip_month
    FROM trips
),
driver_halves AS (
    SELECT 
        driver_id,
        AVG(CASE WHEN trip_month BETWEEN 1 AND 6 THEN efficiency END) AS first_half_raw,
        AVG(CASE WHEN trip_month BETWEEN 7 AND 12 THEN efficiency END) AS second_half_raw
    FROM trip_efficiencies
    GROUP BY driver_id
)
SELECT 
    dh.driver_id,
    d.driver_name,
    ROUND(dh.first_half_raw, 2) AS first_half_avg,
    ROUND(dh.second_half_raw, 2) AS second_half_avg,
    ROUND(dh.second_half_raw - dh.first_half_raw, 2) AS efficiency_improvement
FROM driver_halves dh
JOIN drivers d ON dh.driver_id = d.driver_id
WHERE dh.first_half_raw IS NOT NULL 
  AND dh.second_half_raw IS NOT NULL
  AND (dh.second_half_raw - dh.first_half_raw) > 0
ORDER BY efficiency_improvement DESC, d.driver_name ASC;

```

### Line-by-Line Explanation

* **Lines 1–7 (`trip_efficiencies` CTE):** Creates a Common Table Expression that computes the raw mathematical fuel efficiency for each individual trip (`distance_km / fuel_consumed`) and extracts the numerical calendar month using `MONTH(trip_date)`.
* **Lines 8–15 (`driver_halves` CTE):** Groups the individual trip records by `driver_id`. It utilizes conditional aggregation (`CASE WHEN ... THEN efficiency END`) inside an `AVG()` function to cleanly separate the metrics into two distinct periods: the first half of the year (Months 1-6) and the second half (Months 7-12). Trips falling outside a specific condition return `NULL`, which `AVG()` automatically skips.
* **Lines 16–22 (Main Select & Join):** Connects the computed raw averages back to the `drivers` table to safely append the readable `driver_name`.
* **Lines 23–25 (`WHERE` Clause Filtering):**
* `dh.first_half_raw IS NOT NULL AND dh.second_half_raw IS NOT NULL`: Drops drivers missing data for either of the two halves.
* `(dh.second_half_raw - dh.first_half_raw) > 0`: Excludes any drivers who showed stagnant or negative performance growth.


* **Lines 18–20 (`ROUND` Operations):** Safely rounds the highly accurate mathematical values to 2 decimal places only during this terminal step.
* **Line 26 (`ORDER BY` Schema):** Orders data down from highest to lowest absolute efficiency improvement. In the event of a tie, it falls back to alphabetical order on `driver_name`.

## 5. Python 3.10 (Pandas 2.2.2 & NumPy 1.26.4) Implementation

### Solution Code

```python
import pandas as pd
import numpy as np

def find_improved_efficiency_drivers(drivers: pd.DataFrame, trips: pd.DataFrame) -> pd.DataFrame:
    # 1. Ensure trip_date is in datetime format and extract the month
    trips = trips.copy()
    trips['trip_date'] = pd.to_datetime(trips['trip_date'])
    trips['trip_month'] = trips['trip_date'].dt.month
    
    # 2. Calculate the raw, unrounded fuel efficiency per trip
    trips['efficiency'] = trips['distance_km'] / trips['fuel_consumed']
    
    # 3. Separate efficiencies into first half (Jan-Jun) and second half (Jul-Dec) using numpy.where
    trips['first_half_eff'] = np.where(trips['trip_month'].between(1, 6), trips['efficiency'], np.nan)
    trips['second_half_eff'] = np.where(trips['trip_month'].between(7, 12), trips['efficiency'], np.nan)
    
    # 4. Group by driver and compute the mean (skipping NaNs automatically)
    driver_halves = trips.groupby('driver_id', as_index=False).agg(
        first_half_raw=('first_half_eff', 'mean'),
        second_half_raw=('second_half_eff', 'mean')
    )
    
    # 5. Filter out drivers who don't have trips in BOTH halves of the year
    driver_halves = driver_halves.dropna(subset=['first_half_raw', 'second_half_raw'])
    
    # 6. Calculate raw efficiency improvement and filter for strictly positive improvement
    driver_halves['raw_improvement'] = driver_halves['second_half_raw'] - driver_halves['first_half_raw']
    driver_halves = driver_halves[driver_halves['raw_improvement'] > 0]
    
    # 7. Merge with the drivers DataFrame to get the names
    result = pd.merge(driver_halves, drivers, on='driver_id', how='inner')
    
    # 8. Create the final formatted columns rounded to 2 decimal places
    result['first_half_avg'] = result['first_half_raw'].round(2)
    result['second_half_avg'] = result['second_half_raw'].round(2)
    result['efficiency_improvement'] = result['raw_improvement'].round(2)
    
    # 9. Select target columns and sort by improvement (descending), then driver name (ascending)
    final_cols = ['driver_id', 'driver_name', 'first_half_avg', 'second_half_avg', 'efficiency_improvement']
    result = result[final_cols].sort_values(
        by=['efficiency_improvement', 'driver_name'], 
        ascending=[False, True]
    ).reset_index(drop=True)
    
    # 10. Return the clean finalized structure
    return result

```

### Line-by-Line Explanation

* **Lines 6–8 (Datetime Vector Operations):** Converts the column elements explicitly using `pd.to_datetime()`, then uses the vector accessor `.dt.month` to quickly capture month markers.
* **Line 11 (Series Arithmetic):** Calculates trip efficiency vectors dynamically at full float64 precision.
* **Lines 14–15 (`np.where` Filtering):** Vectorized partitioning using `np.where`. If `.between()` resolves to `True`, it logs the data element; otherwise, it records an explicit `np.nan`.
* **Lines 18–21 (Pandas GroupBy & Aggregation):** Runs `.groupby()` on `driver_id` and aggregates using the `'mean'` identifier. Pandas skips `np.nan` values during mean calculation, mirroring standard SQL behavior.
* **Line 24 (`.dropna()` Filtering):** Removes driver summaries if either of the target period means evaluate to NaN.
* **Lines 27–28 (Delta Calculations):** Subtracts the two float vector values, then filters the slice to include only rows where `raw_improvement > 0`.
* **Line 31 (DataFrame Joining):** Combines the resulting table with the core `drivers` dataset using an inner merge on the matching `driver_id` index.
* **Lines 34–36 (Final Rounding):** Standardizes values down to 2 decimal places using `.round(2)`.
* **Lines 39–43 (Sorting & Re-indexing):** Uses `.sort_values()` with heterogeneous directions (`ascending=[False, True]`) to organize rows by performance gains (descending) and driver names (alphabetically). It wraps up by cleansing row indices with `.reset_index(drop=True)`.
