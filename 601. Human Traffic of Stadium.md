# LeetCode 601: Human Traffic of Stadium

## Problem Description
Write a solution to display the records with three or more consecutive rows with an `id` and the number of people is greater than or equal to 100 for each day.
Return the result table ordered by `visit_date` in ascending order.

---

## The Core Logic: The `id - ROW_NUMBER()` Trick
Instead of using expensive $O(N^3)$ self-joins, all SQL implementations below utilize an optimized window function approach:
1. **Filter** rows where `people >= 100`.
2. **Generate a sequential row number** using `ROW_NUMBER() OVER (ORDER BY id)`.
3. **Subtract** the row number from the `id`. For any consecutive sequence of IDs, this subtraction yields a **constant value** (`id_group`).
4. **Count** the size of each group and filter out groups with a size less than 3.

---

## 1. MySQL Solution
```sql
WITH FilteredStadium AS (
    SELECT 
        id, 
        visit_date, 
        people,
        id - ROW_NUMBER() OVER (ORDER BY id) AS id_group
    FROM Stadium
    WHERE people >= 100
),
GroupCounts AS (
    SELECT 
        id, 
        visit_date, 
        people,
        COUNT(*) OVER (PARTITION BY id_group) AS group_size
    FROM FilteredStadium
)
SELECT id, visit_date, people
FROM GroupCounts
WHERE group_size >= 3
ORDER BY visit_date ASC;

```

)

    id AS "id", 
    TO_CHAR(visit_date, 'YYYY-MM-DD') AS "visit_date", 
    people AS "people"
FROM GroupCounts
WHERE group_size >= 3
ORDER BY visit_date ASC;

## 5. Pandas Solution

```python
import pandas as pd

def human_traffic(stadium: pd.DataFrame) -> pd.DataFrame:
    # Step 1: Filter rows with 100 or more people
    df_filtered = stadium[stadium['people'] >= 100].copy()
    
    if df_filtered.empty:
        return df_filtered
        
    # Step 2: Create group identifier for consecutive rows
    df_filtered['id_group'] = df_filtered['id'] - range(len(df_filtered))
    
    # Step 3: Keep groups that have 3 or more rows
    result = df_filtered.groupby('id_group').filter(lambda x: len(x) >= 3)
    
    # Step 4: Clean up and sort
    result = result.drop(columns=['id_group']).sort_values(by='visit_date')
    
    return result

```
