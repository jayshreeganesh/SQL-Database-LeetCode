# LeetCode 1084: Sales Analysis III

## Problem Description
Find the products that were **only** sold in the first quarter of 2019 (between `2019-01-01` and `2019-03-31` inclusive). 

If a product was sold outside of this date range, or if it has no sales records at all, it should be excluded from the final result.

---

## 1. MySQL
By grouping the sales by `product_id`, we check the minimum and maximum sale dates. If both the `MIN` and `MAX` dates fall within Q1 2019, it guarantees the product was never sold outside of that window.

```sql
SELECT 
    p.product_id, 
    p.product_name
FROM 
    Product p
JOIN 
    Sales s ON p.product_id = s.product_id
GROUP BY 
    p.product_id, p.product_name
HAVING 
    MIN(s.sale_date) >= '2019-01-01' 
    AND MAX(s.sale_date) <= '2019-03-31';

```

## 2. MS SQL Server

In T-SQL, any non-aggregated column in the `SELECT` list must be explicitly declared in the `GROUP BY` clause. Standard ISO date literals (`'YYYY-MM-DD'`) are handled implicitly.

```sql
SELECT 
    p.product_id, 
    p.product_name
FROM 
    Product p
INNER JOIN 
    Sales s ON p.product_id = s.product_id
GROUP BY 
    p.product_id, 
    p.product_name
HAVING 
    MIN(s.sale_date) >= '2019-01-01' 
    AND MAX(s.sale_date) <= '2019-03-31';
```

## 4. Oracle PL/SQL

To avoid potential runtime syntax or formatting issues caused by database-specific `NLS_DATE_FORMAT` parameters, date strings are explicitly wrapped in the `TO_DATE()` function.


## 5. Pandas (Python)

This approach mirrors the SQL aggregate logic by finding each product's date boundaries via `.groupby()` and filtering out any IDs that stray outside Q1.

```python
import pandas as pd

def sales_analysis(product: pd.DataFrame, sales: pd.DataFrame) -> pd.DataFrame:
    # Ensure sale_date is in datetime format for reliable comparison
    sales['sale_date'] = pd.to_datetime(sales['sale_date'])
    
    # Find the min and max sale date for each product
    date_bounds = sales.groupby('product_id')['sale_date'].agg(['min', 'max']).reset_index()
    
    # Filter for products whose sales fall entirely within Q1 2019
    valid_products = date_bounds[
        (date_bounds['min'] >= '2019-01-01') & 
        (date_bounds['max'] <= '2019-03-31')
    ]
    
    # Merge back with the product table to retrieve the product_name
    result = valid_products.merge(product, on='product_id', how='inner')
    
    # Return only the required columns
    return result[['product_id', 'product_name']]

```
