## 1. MySQL Solution

### The Code

```sql
WITH StoreProductStats AS (
    SELECT 
        store_id,
        product_name,
        quantity,
        price,
        RANK() OVER (PARTITION BY store_id ORDER BY price DESC) as rank_desc,
        RANK() OVER (PARTITION BY store_id ORDER BY price ASC) as rank_asc,
        COUNT(*) OVER (PARTITION BY store_id) as total_products
    FROM inventory
),
ImbalanceData AS (
    SELECT 
        s.store_id,
        s.store_name,
        s.location,
        MAX(CASE WHEN sps.rank_desc = 1 THEN sps.product_name END) as most_exp_product,
        MAX(CASE WHEN sps.rank_asc = 1 THEN sps.product_name END) as cheapest_product,
        MAX(CASE WHEN sps.rank_desc = 1 THEN sps.quantity END) as max_price_qty,
        MAX(CASE WHEN sps.rank_asc = 1 THEN sps.quantity END) as min_price_qty
    FROM stores s
    JOIN StoreProductStats sps ON s.store_id = sps.store_id
    WHERE sps.total_products >= 3
    GROUP BY s.store_id, s.store_name, s.location
)
SELECT 
    store_id,
    store_name,
    location,
    most_exp_product,
    cheapest_product,
    ROUND(min_price_qty / max_price_qty, 2) as imbalance_ratio
FROM ImbalanceData
WHERE max_price_qty < min_price_qty
ORDER BY imbalance_ratio DESC, store_name ASC;

```

### Line-by-Line Explanation

* `WITH StoreProductStats AS (`: Initializes a Common Table Expression (CTE) to pre-calculate rankings and counts for our inventory.
* `SELECT store_id, product_name, quantity, price,`: Selects the base columns needed from the inventory table.
* `RANK() OVER (PARTITION BY store_id ORDER BY price DESC) as rank_desc,`: Assigns a rank of 1 to the most expensive product in each store.
* `RANK() OVER (PARTITION BY store_id ORDER BY price ASC) as rank_asc,`: Assigns a rank of 1 to the cheapest product in each store.
* `COUNT(*) OVER (PARTITION BY store_id) as total_products`: Calculates the total number of products each store has, attached to every row.
* `FROM inventory`: Specifies the source table for the first CTE.
* `), ImbalanceData AS (`: Closes the first CTE and starts the second one to aggregate the targeted data.
* `SELECT s.store_id, s.store_name, s.location,`: Selects store identifying information.
* `MAX(CASE WHEN sps.rank_desc = 1 THEN sps.product_name END) as most_exp_product,`: Pivots the most expensive product's name into its own column. `MAX` acts to collapse the NULLs from the group.
* `MAX(CASE WHEN sps.rank_asc = 1 THEN sps.product_name END) as cheapest_product,`: Pivots the cheapest product's name into its own column.
* `MAX(CASE WHEN sps.rank_desc = 1 THEN sps.quantity END) as max_price_qty,`: Extracts the quantity of the most expensive product.
* `MAX(CASE WHEN sps.rank_asc = 1 THEN sps.quantity END) as min_price_qty`: Extracts the quantity of the cheapest product.
* `FROM stores s JOIN StoreProductStats sps ON s.store_id = sps.store_id`: Joins the static store data with our calculated inventory statistics.
* `WHERE sps.total_products >= 3`: Filters out any stores that do not meet the minimum product count threshold requirement.
* `GROUP BY s.store_id, s.store_name, s.location`: Groups the rows by store, activating the `MAX(CASE...)` pivot aggregations above.
* `)`: Closes the second CTE.
* `SELECT store_id, store_name, location, most_exp_product, cheapest_product,`: Selects the final display columns for the output.
* `ROUND(min_price_qty / max_price_qty, 2) as imbalance_ratio`: Calculates the imbalance ratio. MySQL handles decimal division natively, and `ROUND(..., 2)` restricts it to two decimal places.
* `FROM ImbalanceData`: Pulls from our aggregated and pivoted dataset.
* `WHERE max_price_qty < min_price_qty`: Applies the final business rule that the store is only imbalanced if they have fewer expensive items than cheap items.
* `ORDER BY imbalance_ratio DESC, store_name ASC;`: Sorts the final output by the highest imbalance ratio first, falling back to alphabetical sorting by store name for ties.


### Line-by-Line Explanation (Differences from MySQL)

* *(The CTE structure and aggregations remain identical to MySQL. We will focus on the specific MS SQL Server changes.)*
* `ROUND((min_price_qty * 1.0) / max_price_qty, 2) as imbalance_ratio`: This is the critical line for SQL Server. Because `min_price_qty` and `max_price_qty` are integers, SQL Server defaults to **integer division** (e.g., $10 / 20 = 0$). By multiplying `min_price_qty` by `1.0`, we implicitly cast it to a floating-point/decimal number, forcing SQL Server to perform standard decimal division before applying the `ROUND()` function.

## 5. Python (Pandas) Solution

### The Code

```python
import pandas as pd

def find_inventory_imbalance(stores: pd.DataFrame, inventory: pd.DataFrame) -> pd.DataFrame:
    # 1. Filter for stores with >= 3 products
    store_counts = inventory.groupby('store_id').size()
    valid_stores = store_counts[store_counts >= 3].index
    valid_inv = inventory[inventory['store_id'].isin(valid_stores)]
    
    if valid_inv.empty:
        return pd.DataFrame(columns=['store_id', 'store_name', 'location', 
                                     'most_exp_product', 'cheapest_product', 'imbalance_ratio'])
    
    # 2. Get the cheapest product per store
    cheapest = valid_inv.sort_values(by=['store_id', 'price'], ascending=[True, True]) \
                        .drop_duplicates(subset='store_id', keep='first')
    cheapest = cheapest[['store_id', 'product_name', 'quantity']].rename(
        columns={'product_name': 'cheapest_product', 'quantity': 'min_price_qty'}
    )
    
    # 3. Get the most expensive product per store
    expensive = valid_inv.sort_values(by=['store_id', 'price'], ascending=[True, False]) \
                         .drop_duplicates(subset='store_id', keep='first')
    expensive = expensive[['store_id', 'product_name', 'quantity']].rename(
        columns={'product_name': 'most_exp_product', 'quantity': 'max_price_qty'}
    )
    
    # 4. Merge the highest and lowest price stats together
    stats = pd.merge(expensive, cheapest, on='store_id')
    
    # 5. Filter stores where max_price_qty < min_price_qty
    stats = stats[stats['max_price_qty'] < stats['min_price_qty']].copy()
    
    # 6. Calculate the imbalance ratio
    stats['imbalance_ratio'] = (stats['min_price_qty'] / stats['max_price_qty']).round(2)
    
    # 7. Join with stores DataFrame to bring in store_name and location
    result = pd.merge(stats, stores, on='store_id')
    
    # 8. Select final columns and sort the output
    result = result[['store_id', 'store_name', 'location', 
                     'most_exp_product', 'cheapest_product', 'imbalance_ratio']]
    result = result.sort_values(by=['imbalance_ratio', 'store_name'], ascending=[False, True])
    
    return result

```

### Line-by-Line Explanation

* `def find_inventory_imbalance(stores: pd.DataFrame, inventory: pd.DataFrame) -> pd.DataFrame:`: Defines the function signature expecting two pandas DataFrames as input and returning one as output.
* `store_counts = inventory.groupby('store_id').size()`: Groups the inventory by `store_id` and counts the number of rows (products) for each.
* `valid_stores = store_counts[store_counts >= 3].index`: Filters the resulting series to keep only the index (`store_id`) of those with 3 or more products.
* `valid_inv = inventory[inventory['store_id'].isin(valid_stores)]`: Filters the main `inventory` DataFrame to keep only rows belonging to valid stores.
* `if valid_inv.empty: return pd.DataFrame(...)`: Handles edge cases where no stores qualify, returning an empty DataFrame with the correct schema structure.
* `cheapest = valid_inv.sort_values(by=['store_id', 'price'], ascending=[True, True])`: Sorts the data so the cheapest products are at the top of each store's group.
* `.drop_duplicates(subset='store_id', keep='first')`: Drops all rows except the first one for each `store_id`, effectively isolating the single cheapest product.
* `cheapest = cheapest[[...]].rename(columns={...})`: Slices the DataFrame to keep only relevant columns and renames them to match the target output names.
* `expensive = valid_inv.sort_values(by=['store_id', 'price'], ascending=[True, False])`: Re-sorts the data, this time ordering prices descending to bring the most expensive item to the top.
* `.drop_duplicates(subset='store_id', keep='first')`: Drops all rows except the first one for each `store_id`, isolating the single most expensive product.
* `expensive = expensive[[...]].rename(columns={...})`: Slices and renames the columns for the expensive items DataFrame.
* `stats = pd.merge(expensive, cheapest, on='store_id')`: Merges the cheapest and expensive DataFrames side-by-side using the `store_id` as the key.
* `stats = stats[stats['max_price_qty'] < stats['min_price_qty']].copy()`: Filters the merged DataFrame to enforce the business rule where expensive inventory count must be lower than cheap inventory count.
* `stats['imbalance_ratio'] = (stats['min_price_qty'] / stats['max_price_qty']).round(2)`: Calculates the ratio natively (Python 3 handles float division automatically) and rounds it to 2 decimal places.
* `result = pd.merge(stats, stores, on='store_id')`: Joins our statistical DataFrame with the original `stores` DataFrame to pull in the `store_name` and `location`.
* `result = result[[...]]`: Reorders the columns to match exactly what LeetCode expects.
* `result = result.sort_values(by=['imbalance_ratio', 'store_name'], ascending=[False, True])`: Sorts the final DataFrame by the imbalance ratio descending, using store name ascending as a tiebreaker.
* `return result`: Returns the final processed DataFrame to the testing suite.
