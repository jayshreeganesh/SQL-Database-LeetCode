# Find Valid Emails - Multi-Language Solutions

This document contains the verified, correct implementations for the [Find Valid Emails](https://leetcode.com/problems/find-valid-emails/) problem across multiple SQL dialects and Python Pandas.

---

## 1. MySQL

MySQL supports native regular expressions via the `REGEXP` operator.

```sql
SELECT user_id, email
FROM Users
WHERE email REGEXP '^[a-zA-Z0-9_]+@[a-zA-Z]+\\.com$'
ORDER BY user_id ASC;

```

---

## 2. PostgreSQL 16

PostgreSQL uses the case-sensitive regular expression match operator `~`. Character classes like `[.]` avoid backslash-escaping issues.

```sql
SELECT user_id, email
FROM Users
WHERE email ~ '^[a-zA-Z0-9_]+@[a-zA-Z]+[.]com$'
ORDER BY user_id ASC;

```

---

## 3. MS SQL Server 2019

Because MS SQL Server lacks a native `REGEXP` function, standard pattern-matching logic is simulated using inverted `LIKE` and `NOT LIKE` operators with wildcard ranges.

```sql
SELECT user_id, email
FROM Users
WHERE email LIKE '_%@_%.com'
  AND email NOT LIKE '%@%@%'
  AND email NOT LIKE '%[^a-zA-Z0-9_]%@%'
  AND email NOT LIKE '%@%[^a-zA-Z]%.com'
ORDER BY user_id ASC;

```

---

## 4. Oracle SQL 11.2

Oracle SQL implements regular expressions natively via the built-in `REGEXP_LIKE` condition evaluation function.

```sql
SELECT user_id, email
FROM Users
WHERE REGEXP_LIKE(email, '^[a-zA-Z0-9_]+@[a-zA-Z]+[.]com$')
ORDER BY user_id ASC;

```

---

## 5. Python 3.10 (Pandas 2.2.2 & NumPy 1.26.4)

Pandas uses the `.str.match()` method to evaluate patterns from the beginning of a string. `na=False` ensures robust handling of missing data.

```python
import pandas as pd

def find_valid_emails(users: pd.DataFrame) -> pd.DataFrame:
    # Raw string (r'...') prevents Python string escape sequence errors
    pattern = r'^[a-zA-Z0-9_]+@[a-zA-Z]+\.com$'
    
    # Filter for valid matching rows
    valid_emails_df = users[users['email'].str.match(pattern, na=False)]
    
    # Sort results
    return valid_emails_df.sort_values(by='user_id', ascending=True)

```
