# LeetCode 3475. DNA Pattern Recognition

## Problem Description
The goal is to analyze DNA sequences from the `Samples` table and identify specific genetic motifs or features based on given rules:
* **`has_start`**: `1` if the sequence begins with `'ATG'`, `0` otherwise.
* **`has_stop`**: `1` if the sequence ends with `'TAA'`, `'TAG'`, or `'TGA'`, `0` otherwise.
* **`has_atat`**: `1` if the sequence contains the motif `'ATAT'` anywhere, `0` otherwise.
* **`has_ggg`**: `1` if the sequence contains at least 3 consecutive `'G'`s (`'GGG'`) anywhere, `0` otherwise.

The output must be ordered by `sample_id` in ascending order.

---

## 1. MySQL

```sql
SELECT 
    sample_id,
    dna_sequence,
    species,
    CASE WHEN dna_sequence LIKE 'ATG%' THEN 1 ELSE 0 END AS has_start,
    CASE WHEN dna_sequence LIKE '%TAA' OR dna_sequence LIKE '%TAG' OR dna_sequence LIKE '%TGA' THEN 1 ELSE 0 END AS has_stop,
    CASE WHEN dna_sequence LIKE '%ATAT%' THEN 1 ELSE 0 END AS has_atat,
    CASE WHEN dna_sequence LIKE '%GGG%' THEN 1 ELSE 0 END AS has_ggg
FROM 
    Samples
ORDER BY 
    sample_id ASC;

```

## 5. Pandas

```python
import pandas as pd

def analyze_dna_patterns(samples: pd.DataFrame) -> pd.DataFrame:
    # 1. Check if it starts with 'ATG'
    samples['has_start'] = samples['dna_sequence'].str.startswith('ATG').astype(int)
    
    # 2. Check if it ends with 'TAA', 'TAG', or 'TGA' using regex and '$' anchor
    samples['has_stop'] = samples['dna_sequence'].str.contains(r'(TAA|TAG|TGA)$', regex=True).astype(int)
    
    # 3. Check if it contains 'ATAT' anywhere (regex=False for faster literal match)
    samples['has_atat'] = samples['dna_sequence'].str.contains('ATAT', regex=False).astype(int)
    
    # 4. Check if it contains 'GGG' anywhere 
    samples['has_ggg'] = samples['dna_sequence'].str.contains('GGG', regex=False).astype(int)
    
    # Sort by sample_id in ascending order
    return samples.sort_values(by='sample_id', ascending=True)
```
