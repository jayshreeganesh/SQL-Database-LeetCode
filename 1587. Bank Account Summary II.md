# LeetCode 1587: Bank Account Summary II

## Problem Description
Given a `Users` table and a `Transactions` table, write a solution to report the name and balance of users with a balance higher than 10,000. The balance of an account is equal to the sum of the amounts of all transactions involving that account.

Return the result table in **any order**.

---

## 1. MySQL
MySQL allows for more flexible grouping rules if the columns are functionally dependent, but it is best practice to filter using the aggregate function in the `HAVING` clause.

```sql
SELECT 
    u.name, 
    SUM(t.amount) AS balance
FROM 
    Users u
JOIN 
    Transactions t ON u.account = t.account
GROUP BY 
    u.account
HAVING 
    SUM(t.amount) > 10000;

```

---

## 2. MS SQL Server

MS SQL Server strictly requires any non-aggregated column in the `SELECT` list (like `u.name`) to be explicitly included inside the `GROUP BY` clause.

```sql
SELECT 
    u.name, 
    SUM(t.amount) AS balance
FROM 
    Users u
JOIN 
    Transactions t ON u.account = t.account
GROUP BY 
    u.account, 
    u.name
HAVING 
    SUM(t.amount) > 10000;

```

## 3. PostgreSQL

PostgreSQL follows standard ANSI SQL rules identical to MS SQL Server, demanding full column grouping and evaluating `HAVING` before `SELECT` aliases are processed.


## 5. Pandas (Python)

The Python solution mimics the relational steps: grouping transactions, joining tables using `merge()`, applying boolean indexing filtering, and reshaping columns.

```python
import pandas as pd

def account_summary(users: pd.DataFrame, transactions: pd.DataFrame) -> pd.DataFrame:
    # 1. Group transactions by account and sum the amounts
    grouped_trans = transactions.groupby('account')['amount'].sum().reset_index()
    
    # 2. Merge with the users DataFrame to get the names
    merged_df = pd.merge(users, grouped_trans, on='account', how='inner')
    
    # 3. Filter for balances strictly greater than 10,000
    filtered_df = merged_df[merged_df['amount'] > 10000]
    
    # 4. Select the required columns and rename them to match the expected output
    result = filtered_df[['name', 'amount']].rename(columns={'name': 'NAME', 'amount': 'BALANCE'})
    
    return result

```
