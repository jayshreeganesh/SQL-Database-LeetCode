

# LeetCode 3642: Find Books with Polarized Opinions

## Problem Summary
We need to find books with polarized reader opinions from a database. 
- **Polarized Criteria**: A book must have at least one rating $\ge 4$ AND at least one rating $\le 2$.
- **Activity Volume**: A book must have at least 5 total reading sessions.
- **Polarization Score**: At least 60% ($\ge 0.60$) of all its ratings must be "extreme" (either $\le 2$ or $\ge 4$).
- **Output Requirements**: Calculate `rating\_spread ( $\text{max\_rating} - \text{min\_rating}$ ) and the `polarization_score` rounded to 2 decimal places. Sort by `polarization_score` descending, then by `title` descending.

---

## 1. MySQL 8.0

### Solution: Single-Level Aggregation with HAVING
MySQL 8.0 allows referencing column aliases dynamically in the `HAVING` clause, which makes a single-level aggregation highly efficient.

```sql
SELECT 
    b.book_id,
    b.title,
    b.author,
    b.genre,
    b.pages,
    (MAX(s.session_rating) - MIN(s.session_rating)) AS rating_spread,
    ROUND(
        SUM(CASE WHEN s.session_rating <= 2 OR s.session_rating >= 4 THEN 1 ELSE 0 END) 
        / COUNT(s.session_id), 
        2
    ) AS polarization_score
FROM books b
JOIN reading_sessions s ON b.book_id = s.book_id
GROUP BY 
    b.book_id, 
    b.title, 
    b.author, 
    b.genre, 
    b.pages
HAVING 
    COUNT(s.session_id) >= 5
    AND MAX(CASE WHEN s.session_rating >= 4 THEN 1 ELSE 0 END) = 1
    AND MAX(CASE WHEN s.session_rating <= 2 THEN 1 ELSE 0 END) = 1
    AND polarization_score >= 0.6
ORDER BY 
    polarization_score DESC, 
    b.title DESC;

```

### Line-by-Line Explanation

* **`SELECT ...`**: Identifies the core metadata columns from the `books` table to retain in the final output.
* **`(MAX(s.session_rating) - MIN(s.session_rating)) AS rating_spread`**: Subtracts the absolute lowest session score from the highest to compute the maximum evaluation spread.
* **`ROUND(SUM(CASE WHEN ...) / COUNT(...), 2) AS polarization_score`**: Divides the total number of extreme reviews (ratings $\le 2$ or $\ge 4$) by the overall session count for that book, rounding the result to 2 decimal places.
* **`FROM books b JOIN reading_sessions s ON b.book_id = s.book_id`**: Performs an `INNER JOIN` linking sessions directly to their respective book metadata records.
* **`GROUP BY b.book_id, ...`**: Groups the metrics by unique book metadata elements, fulfilling strict ANSI-SQL standards.
* **`HAVING COUNT(s.session_id) >= 5`**: Filters out any book containing fewer than 5 reading interactions.
* **`AND MAX(CASE WHEN s.session_rating >= 4 THEN 1 ELSE 0 END) = 1`**: Evaluates all ratings per group; returns `1` if at least one record satisfies the high-rating condition ($\ge 4$).
* **`AND MAX(CASE WHEN s.session_rating <= 2 THEN 1 ELSE 0 END) = 1`**: Evaluates all ratings per group; returns `1` if at least one record satisfies the low-rating condition ($\le 2$).
* **`AND polarization_score >= 0.6`**: Filters out books where extreme ratings make up less than 60% of total ratings.
* **`ORDER BY polarization_score DESC, b.title DESC;`**: Enforces primary descending order by the computed polarization metric, using reverse alphabetical order of book titles as a tie-breaker.

## 2. MS SQL Server 2019

### Solution: Common Table Expression (CTE) with Float Cast

SQL Server performs integer division if both elements are integers, and it blocks utilizing a `SELECT` column alias inside `HAVING`. We bypass this by casting data types and evaluating criteria inside a CTE.

```sql
WITH ProcessedBooks AS (
    SELECT 
        b.book_id,
        b.title,
        b.author,
        b.genre,
        b.pages,
        (MAX(s.session_rating) - MIN(s.session_rating)) AS rating_spread,
        ROUND(
            CAST(SUM(CASE WHEN s.session_rating <= 2 OR s.session_rating >= 4 THEN 1 ELSE 0 END) AS FLOAT) 
            / COUNT(s.session_id), 
            2
        ) AS polarization_score,
        COUNT(s.session_id) AS total_sessions,
        MAX(CASE WHEN s.session_rating >= 4 THEN 1 ELSE 0 END) AS has_high,
        MAX(CASE WHEN s.session_rating <= 2 THEN 1 ELSE 0 END) AS has_low
    FROM books b
    JOIN reading_sessions s ON b.book_id = s.book_id
    GROUP BY 
        b.book_id, 
        b.title, 
        b.author, 
        b.genre, 
        b.pages
)
SELECT 
    book_id, title, author, genre, pages, rating_spread, polarization_score
FROM ProcessedBooks
WHERE 
    total_sessions >= 5
    AND has_high = 1
    AND has_low = 1
    AND polarization_score >= 0.6
ORDER BY 
    polarization_score DESC, 
    title DESC;

```

### Line-by-Line Explanation

* **`WITH ProcessedBooks AS (...)`**: Establishes an isolation layer/CTE block to aggregate transaction metrics safely before primary record filtering.
* **`CAST(SUM(...) AS FLOAT) / COUNT(...)`**: Converts the extreme session count into an explicit floating-point value. This forces SQL Server to perform fractional division rather than truncating integers.
* **`MAX(CASE WHEN s.session_rating >= 4 THEN 1 ELSE 0 END) AS has_high`**: Flags books with a `1` if they have at least one high score, and a `0` otherwise.
* **`MAX(CASE WHEN s.session_rating <= 2 THEN 1 ELSE 0 END) AS has_low`**: Flags books with a `1` if they have at least one low score, and a `0` otherwise.
* **`SELECT ... FROM ProcessedBooks`**: Selects the computed metrics out from our isolated CTE container layout.
* **`WHERE total_sessions >= 5 AND has_high = 1 AND has_low = 1 AND polarization_score >= 0.6`**: Applies all the filtering rules cleanly at the outer layer using the precomputed flags and scores.
* **`ORDER BY polarization_score DESC, title DESC;`**: Sequences records with the highest polarization scores appearing first.

## 3. PostgreSQL 16

### Solution: CTE using Native Boolean Aggregation (`BOOL_OR`)

PostgreSQL natively supports logical boolean reductions over aggregations via `BOOL_OR()`, removing the need for `MAX(CASE WHEN...)` flag checks.

```sql
WITH ProcessedBooks AS (
    SELECT 
        b.book_id,
        b.title,
        b.author,
        b.genre,
        b.pages,
        (MAX(s.session_rating) - MIN(s.session_rating)) AS rating_spread,
        ROUND(
            SUM(CASE WHEN s.session_rating <= 2 OR s.session_rating >= 4 THEN 1 ELSE 0 END)::NUMERIC 
            / COUNT(s.session_id), 
            2
        ) AS polarization_score,
        COUNT(s.session_id) AS total_sessions,
        BOOL_OR(s.session_rating >= 4) AS has_high,
        BOOL_OR(s.session_rating <= 2) AS has_low
    FROM books b
    JOIN reading_sessions s ON b.book_id = s.book_id
    GROUP BY 
        b.book_id, 
        b.title, 
        b.author, 
        b.genre, 
        b.pages
)
SELECT 
    book_id, title, author, genre, pages, rating_spread, polarization_score
FROM ProcessedBooks
WHERE 
    total_sessions >= 5
    AND has_high = TRUE
    AND has_low = TRUE
    AND polarization_score >= 0.6
ORDER BY 
    polarization_score DESC, 
    title DESC;

```

### Line-by-Line Explanation

* **`SUM(CASE WHEN ...)::NUMERIC`**: Uses the PostgreSQL type cast operator (`::NUMERIC`) to convert the sum of extreme ratings. This ensures the division retains full fractional precision.
* **`BOOL_OR(s.session_rating >= 4) AS has_high`**: Uses Postgres' native `BOOL_OR` aggregate function to return `TRUE` if even one row in the group matches the condition ($\ge 4$).
* **`BOOL_OR(s.session_rating <= 2) AS has_low`**: Returns `TRUE` if at least one session has a low rating ($\le 2$).
* **`WHERE has_high = TRUE AND has_low = TRUE`**: Standard boolean validation filters implemented during row collection within the main selection body.

## 4. Oracle SQL 11.2

### Solution: Strict ANSI Grouping via CTE

Oracle 11g lacks explicit boolean data types in its SQL engine. We use explicit numeric casting to avoid issues with database-specific NLS parameter variations.

```sql
WITH ProcessedBooks AS (
    SELECT 
        b.book_id,
        b.title,
        b.author,
        b.genre,
        b.pages,
        (MAX(s.session_rating) - MIN(s.session_rating)) AS rating_spread,
        ROUND(
            SUM(CASE WHEN s.session_rating <= 2 OR s.session_rating >= 4 THEN 1 ELSE 0 END) 
            / CAST(COUNT(s.session_id) AS NUMBER), 
            2
        ) AS polarization_score,
        COUNT(s.session_id) AS total_sessions,
        MAX(CASE WHEN s.session_rating >= 4 THEN 1 ELSE 0 END) AS has_high,
        MAX(CASE WHEN s.session_rating <= 2 THEN 1 ELSE 0 END) AS has_low
    FROM books b
    JOIN reading_sessions s ON b.book_id = s.book_id
    GROUP BY 
        b.book_id, 
        b.title, 
        b.author, 
        b.genre, 
        b.pages
)
SELECT 
    book_id, title, author, genre, pages, rating_spread, polarization_score
FROM ProcessedBooks
WHERE 
    total_sessions >= 5
    AND has_high = 1
    AND has_low = 1
    AND polarization_score >= 0.6
ORDER BY 
    polarization_score DESC, 
    title DESC;

```

### Line-by-Line Explanation

* **`CAST(COUNT(s.session_id) AS NUMBER)`**: Explicitly type-casts the total count to an Oracle `NUMBER` type to ensure consistent floating-point division across different database environments.
* **`GROUP BY b.book_id, b.title, ...`**: Explicitly includes all non-aggregated descriptive attributes in the `GROUP BY` clause to prevent Oracle's strict compiler from throwing an `ORA-00979: not a GROUP BY expression` error.
* **`WHERE has_high = 1 AND has_low = 1`**: Evaluates the binary flags as integer conditions (`= 1`) to ensure compatibility with Oracle 11g's data types.

## 5. Python 3.10 / Pandas 2.2.2 / NumPy 1.26.4

### Solution: Vectorized Aggregation with Floating Epsilon Adjustment

This approach uses vectorized operations for speed and includes a tiny epsilon adjustment (`1e-9`) before rounding. This ensures that floating-point values (like $0.625$) are correctly rounded up to match database-style rounding.

```python
import pandas as pd
import numpy as np

def find_polarized_books(books: pd.DataFrame, reading_sessions: pd.DataFrame) -> pd.DataFrame:
    # 1. Group reading sessions by book_id to calculate metrics
    stats = reading_sessions.groupby('book_id').agg(
        total_sessions=('session_id', 'count'),
        min_rating=('session_rating', 'min'),
        max_rating=('session_rating', 'max'),
        extreme_sessions=('session_rating', lambda x: ((x <= 2) | (x >= 4)).sum())
    ).reset_index()
    
    # 2. Filter out books with fewer than 5 sessions early for efficiency
    stats = stats[stats['total_sessions'] >= 5]
    
    # 3. Apply polarization conditions: must have at least one high (>=4) and one low (<=2) rating
    has_high = reading_sessions[reading_sessions['session_rating'] >= 4]['book_id'].unique()
    has_low = reading_sessions[reading_sessions['session_rating'] <= 2]['book_id'].unique()
    
    stats = stats[stats['book_id'].isin(has_high) & stats['book_id'].isin(has_low)]
    
    # 4. Calculate the final metrics
    stats['rating_spread'] = stats['max_rating'] - stats['min_rating']
    
    # Add a tiny epsilon (1e-9) to handle floating-point precision differences before rounding
    stats['polarization_score'] = ((stats['extreme_sessions'] / stats['total_sessions']) + 1e-9).round(2)
    
    # Filter by polarization score threshold
    stats = stats[stats['polarization_score'] >= 0.60]
    
    # 5. Merge back with the books metadata
    result = books.merge(stats[['book_id', 'rating_spread', 'polarization_score']], on='book_id', how='inner')
    
    # 6. Sort by polarization_score descending, then title descending
    result = result.sort_values(
        by=['polarization_score', 'title'], 
        ascending=[False, False]
    )
    
    return result

```

### Line-by-Line Explanation

* **`reading_sessions.groupby('book_id').agg(...)`**: Groups the session data by `book_id` and calculates multiple summary metrics at once.
* **`extreme_sessions=('session_rating', lambda x: ((x <= 2) | (x >= 4)).sum())`**: Uses a vectorized bitwise OR (`|`) to count how many ratings are extreme ($\le 2$ or $\ge 4$).
* **`stats = stats[stats['total_sessions'] >= 5]`**: Filters out rows with fewer than 5 sessions early on to keep the data size manageable.
* **`has_high = reading_sessions[...]['book_id'].unique()`**: Drops down to the base session array to extract a unique list of IDs that received high scores ($\ge 4$).
* **`stats[...]['book_id'].isin(has_high) & ...`**: Uses boolean indexing to only keep books that have at least one high rating and one low rating.
* **`stats['rating_spread'] = stats['max_rating'] - stats['min_rating']`**: Vectorized subtraction to find the rating spread for each book.
* **`((stats['extreme_sessions'] / stats['total_sessions']) + 1e-9).round(2)`**: Divides the extreme sessions by total sessions, adds a tiny epsilon value (`1e-9`) to fix floating-point rounding edge-cases, and rounds the score to 2 decimal places.
* **`books.merge(..., on='book_id', how='inner')`**: Performs an inner join to pull the descriptive book metadata (like title and author) back into our results.
* **`result.sort_values(by=['polarization_score', 'title'], ascending=[False, False])`**: Sorts the final DataFrame by the polarization score in descending order, and resolves ties by sorting titles in reverse alphabetical order.
