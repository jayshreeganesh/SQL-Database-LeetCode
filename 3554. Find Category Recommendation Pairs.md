# 3554. Find Category Recommendation Pairs

## Method Explanation

1. **Map Products to Categories:** Join `ProductPurchases` with `ProductInfo` to find the category for each purchased product. Group by `user_id` and `category` to secure a distinct list of categories each user interacted with (eliminating duplicate category entries for a single user).
2. **Self-Join to Create Pairs:** Perform a self-join on this distinct list using `user_id` to pair up different categories purchased by the *same* user.
3. **Filter Out Duplicates:** Apply the strict condition `category_x < category_y` to remove reverse duplicates (e.g., keeping A-B and discarding B-A) and to prevent any category from pairing with itself.
4. **Aggregate and Filter:** Group by the paired categories, count the unique users using `COUNT`, and use a `HAVING` clause (or filter condition) to retain only pairs supported by 3 or more unique customers.
5. **Sort:** Order the final dataset by customer count in descending order, then alphabetically by the first and second categories.

---

## 1. MySQL

```sql
WITH UserCategories AS (
    SELECT DISTINCT 
        p.user_id, 
        i.category
    FROM ProductPurchases p
    JOIN ProductInfo i ON p.product_id = i.product_id
)
SELECT 
    c1.category AS category1,
    c2.category AS category2,
    COUNT(c1.user_id) AS customer_count
FROM UserCategories c1
JOIN UserCategories c2 ON c1.user_id = c2.user_id
WHERE c1.category < c2.category
GROUP BY c1.category, c2.category
HAVING COUNT(c1.user_id) >= 3
ORDER BY 
    customer_count DESC, 
    category1 ASC, 
    category2 ASC;

```

## 5. Pandas (Python)

```python
import pandas as pd

def find_category_recommendation_pairs(product_purchases: pd.DataFrame, product_info: pd.DataFrame) -> pd.DataFrame:
    # 1 & 2. Merge and get unique user-category pairs
    df = pd.merge(product_purchases, product_info, on='product_id')[['user_id', 'category']].drop_duplicates()
    
    # 3. Self-merge on user_id to find category pairs per user
    merged = pd.merge(df, df, on='user_id')
    
    # 4. Filter out duplicate/self pairs (keep category_x < category_y)
    pairs = merged[merged['category_x'] < merged['category_y']]
    
    # 5. Group by pairs and count unique customers
    result = pairs.groupby(['category_x', 'category_y']).size().reset_index(name='customer_count')
    
    # Filter for pairs with at least 3 unique customers
    result = result[result['customer_count'] >= 3]
    
    # 6. Rename columns to match the output schema
    result = result.rename(columns={'category_x': 'category1', 'category_y': 'category2'})
    
    # Sort by customer_count descending, then alphabetically by category1 and category2
    result = result.sort_values(by=['customer_count', 'category1', 'category2'], ascending=[False, True, True])
    
    return result
```
