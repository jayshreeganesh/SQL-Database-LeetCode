# LeetCode: Trips and Users Solutions

Solutions for the **Trips and Users** problem across five different languages/dialects: MySQL, MS SQL Server, PostgreSQL, Oracle, and Pandas.

---

## 1. MySQL
```sql
SELECT 
    request_at AS Day,
    ROUND(
        SUM(CASE WHEN status LIKE 'cancelled%' THEN 1 ELSE 0 END) / COUNT(*), 
        2
    ) AS `Cancellation Rate`
FROM 
    Trips
WHERE 
    client_id NOT IN (SELECT users_id FROM Users WHERE banned = 'Yes')
    AND driver_id NOT IN (SELECT users_id FROM Users WHERE banned = 'Yes')
    AND request_at BETWEEN '2013-10-01' AND '2013-10-03'
GROUP BY 
    request_at;

```

## 5. Pandas

```python
import pandas as pd

def trips_and_users(trips: pd.DataFrame, users: pd.DataFrame) -> pd.DataFrame:
    # 1. Get a set of users who are banned
    banned_users = users[users['banned'] == 'Yes']['users_id']
    
    # 2. Filter out trips where either the client or the driver is banned
    # Also filter for the specific date range
    valid_trips = trips[
        (~trips['client_id'].isin(banned_users)) & 
        (~trips['driver_id'].isin(banned_users)) & 
        (trips['request_at'].between('2013-10-01', '2013-10-03'))
    ].copy()
    
    # If no trips match the criteria, return an empty DataFrame with expected columns
    if valid_trips.empty:
        return pd.DataFrame(columns=['Day', 'Cancellation Rate'])
    
    # 3. Create a binary indicator for cancellation (1 if cancelled, 0 if completed)
    valid_trips['is_cancelled'] = valid_trips['status'].str.startswith('cancelled').astype(int)
    
    # 4. Group by 'request_at' and calculate the mean (which naturally gives the rate)
    result = (
        valid_trips.groupby('request_at')['is_cancelled']
        .mean()
        .round(2)
        .reset_index()
    )
    
    # 5. Rename columns to match the expected output format
    result.columns = ['Day', 'Cancellation Rate']
    
    return result

```
