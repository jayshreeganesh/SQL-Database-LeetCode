
# Most Common Course Pairs - Multi-Language Solutions

This document provides fully optimized, case-insensitive implementations for finding the most common consecutive course pairs taken by top-performing students.

---

## 1. MySQL 8.0 Solution

```sql
WITH top_students AS (
    SELECT user_id
    FROM course_completions
    GROUP BY user_id
    HAVING COUNT(course_id) >= 5 AND AVG(course_rating) >= 4
),
course_transitions AS (
    SELECT 
        course_name AS first_course,
        LEAD(course_name) OVER(PARTITION BY user_id ORDER BY completion_date) AS second_course
    FROM course_completions
    WHERE user_id IN (SELECT user_id FROM top_students)
)
SELECT 
    first_course,
    second_course,
    COUNT(*) AS transition_count
FROM course_transitions
WHERE second_course IS NOT NULL
GROUP BY first_course, second_course
ORDER BY 
    transition_count DESC, 
    LOWER(first_course) ASC, 
    LOWER(second_course) ASC;

```

### Line-by-Line Explanation:

* **`WITH top_students AS (...)`**: Defines a Common Table Expression (CTE) to isolate qualified users.
* **`GROUP BY user_id HAVING COUNT(course_id) >= 5 AND AVG(course_rating) >= 4`**: Aggregates data by student, ensuring they completed at least 5 courses and maintained an average rating of 4 or above.
* **`course_transitions AS (...)`**: Defines a secondary CTE to map chronological course progressions.
* **`LEAD(course_name) OVER(PARTITION BY user_id ORDER BY completion_date)`**: Looks ahead to the next row within the same user's timeline to identify the `second_course`.
* **`WHERE second_course IS NOT NULL`**: Filters out the final course completed by each student since it has no trailing pair.
* **`GROUP BY first_course, second_course`**: Groups identical transitions together to calculate collective frequencies.
* **`ORDER BY transition_count DESC, LOWER(first_course) ASC, LOWER(second_course) ASC`**: Sorts by frequency dynamically, falling back on case-insensitive alphabetical sorting via `LOWER()` to prevent case mismatches.

### Line-by-Line Explanation:

* **`LEAD(...) OVER (PARTITION BY ... ORDER BY ...)`**: T-SQL's window engine segments navigation tracking cleanly within individual user boundaries sorted sequentially by completion dates.
* **`LOWER(first_course) ASC`**: Ensures cross-collation sorting safety. Forces case-insensitive chronological grouping order across varied database instance collations.

## 5. Python 3.10 with Pandas 2.2.2 & NumPy 1.26.4 Solution

```python
import numpy as np
import pandas as pd


def topLearnerCourseTransitions(
    course_completions: pd.DataFrame,
) -> pd.DataFrame:
    # Step 1: Aggregate totals and filter for top-performing students
    student_stats = (
        course_completions.groupby("user_id")
        .agg(course_count=("course_id", "count"), avg_rating=("course_rating", "mean"))
        .reset_index()
    )

    top_students = student_stats[
        (student_stats["course_count"] >= 5) & (student_stats["avg_rating"] >= 4)
    ]["user_id"]

    filtered_df = course_completions[
        course_completions["user_id"].isin(top_students)
    ].copy()

    # Step 2: Sequence sorting and chronological pairing per user
    filtered_df = filtered_df.sort_values(by=["user_id", "completion_date"])

    filtered_df["first_course"] = filtered_df["course_name"]
    filtered_df["second_course"] = filtered_df.groupby("user_id")[
        "course_name"
    ].shift(-1)

    # Remove rows where there is no subsequent course
    transitions = filtered_df.dropna(subset=["second_course"])

    # Step 3: Count transition frequencies
    result = (
        transitions.groupby(["first_course", "second_course"])
        .size()
        .reset_index(name="transition_count")
    )

    # Step 4: Sort by criteria (transition_count DESC, case-insensitive alphabetical ASC)
    result = result.sort_values(
        by=["transition_count", "first_course", "second_course"],
        ascending=[False, True, True],
        key=lambda col: (
            col.str.lower() if col.name in ["first_course", "second_course"] else col
        ),
    )

    return result

```

### Line-by-Line Explanation:

* **`.groupby("user_id").agg(...)`**: Batches user accounts to yield total volumes alongside absolute structural averages.
* **`.isin(top_students)`**: Filters out and drops any metrics tied to accounts outside the target group.
* **`.sort_values(by=["user_id", "completion_date"])`**: Arranges the remaining entries cleanly to guarantee precise linear mapping timeline evaluations.
* **`.shift(-1)`**: Moves course arrays backward by one step per user cluster, cleanly mirroring SQL's `LEAD()` function.
* **`.dropna(subset=["second_course"])`**: Prunes trailing blank values resulting from shifts on tail-end sequence index limits.
* **`key=lambda col: col.str.lower() ...`**: Modifies the custom evaluation targets during execution sorting bounds, matching case-insensitive demands while maintaining original string representation schemas.
