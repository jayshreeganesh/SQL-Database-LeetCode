# 1965. Employees With Missing Information

## Problem Description
Find the IDs of all employees with missing information. An employee's information is missing if:
1. The employee's **name** is missing, or
2. The employee's **salary** is missing.

Return the result table ordered by `employee_id` in **ascending order**.

---

## 1. MySQL
Since MySQL does not natively support `FULL OUTER JOIN`, a `UNION` of two queries filtering out matching IDs is the cleanest approach.

```sql
SELECT employee_id 
FROM Employees 
WHERE employee_id NOT IN (SELECT employee_id FROM Salaries)

UNION

SELECT employee_id 
FROM Salaries 
WHERE employee_id NOT IN (SELECT employee_id FROM Employees)

ORDER BY employee_id ASC;

```

---

## 2. MS SQL Server (T-SQL)

MS SQL Server natively supports `FULL OUTER JOIN`, which allows us to find rows where either table has missing data in a single pass.

```sql
SELECT 
    COALESCE(e.employee_id, s.employee_id) AS employee_id
FROM 
    Employees e
FULL OUTER JOIN 
    Salaries s ON e.employee_id = s.employee_id
WHERE 
    e.name IS NULL 
    OR s.salary IS NULL
ORDER BY 
    employee_id ASC;

```

## 3. PostgreSQL

PostgreSQL handles `FULL OUTER JOIN` exceptionally well. Alternatively, you can use the `EXCEPT` set operator.

### Approach 1: Full Outer Join (Recommended)

```sql
SELECT 
    COALESCE(e.employee_id, s.employee_id) AS employee_id
FROM 
    Employees e
FULL OUTER JOIN 
    Salaries s ON e.employee_id = s.employee_id
WHERE 
    e.name IS NULL 
    OR s.salary IS NULL
ORDER BY 
    employee_id ASC;

```

### Approach 2: Using Set Operators (`EXCEPT`)

```sql
(SELECT employee_id FROM Employees
 EXCEPT
 SELECT employee_id FROM Salaries)

UNION

(SELECT employee_id FROM Salaries
 EXCEPT
 SELECT employee_id FROM Employees)

ORDER BY employee_id ASC;

```

## 4. Oracle PL/SQL

Oracle uses the `MINUS` operator instead of `EXCEPT` for set differences, or you can use `NVL`/`COALESCE` with a full join.

### Approach 1: Full Outer Join with `NVL`

```sql

    NVL(e.employee_id, s.employee_id) AS employee_id
FROM 
    Employees e
```

## 5. Pandas (Python)

Two efficient ways to solve this in Pandas: using an outer merge with an indicator flag, or leveraging Python's set symmetric difference (`^`).

### Approach 1: Outer Merge (Idiomatic Pandas)

```python
import pandas as pd

def find_employees(employees: pd.DataFrame, salaries: pd.DataFrame) -> pd.DataFrame:
    # Outer join tracking row origins
    merged = pd.merge(employees, salaries, on='employee_id', how='outer', indicator=True)
    
    # Filter out rows that are present in both dataframes
    missing_info = merged[merged['_merge'] != 'both']
    
    # Format and sort output
    return missing_info[['employee_id']].sort_values(by='employee_id')

```

### Approach 2: Symmetric Difference (Fast Set Operations)

```python
import pandas as pd

def find_employees(employees: pd.DataFrame, salaries: pd.DataFrame) -> pd.DataFrame:
    emp_ids = set(employees['employee_id'])
    sal_ids = set(salaries['employee_id'])
    
    # Find IDs unique to either set
    missing_ids = list(emp_ids ^ sal_ids)
    
    return pd.DataFrame({'employee_id': missing_ids}).sort_values(by='employee_id')

```
