# Find Product Recommendation Pairs — Multi-Language Solutions

## Problem Overview
The objective is to identify pairs of products that are frequently purchased together by the same users. Specifically, we want to find product pairs that have been co-purchased by **at least 3 unique customers**, returning their respective IDs, categories, and the shared customer count.

### Constraints & Logic:
1. **Self-Join / Pairing**: Products must be paired based on a shared `user_id`.
2. **De-duplication**: To avoid mirror pairs (e.g., reporting both `[101, 102]` and `[102, 101]`) and self-pairing (`[101, 101]`), we enforce the condition `product1_id < product2_id`.
3. **Filtering**: Only pairs with a distinct customer count $\ge 3$ are retained.
4. **Ordering**: Results are ordered by `customer_count` descending, then by `product1_id` ascending, and finally by `product2_id` ascending.

## 1. MySQL

```sql
SELECT 
    p1.product_id AS product1_id,
    p2.product_id AS product2_id,
    info1.category AS product1_category,
    info2.category AS product2_category,
    COUNT(DISTINCT p1.user_id) AS customer_count
FROM 
    ProductPurchases p1
JOIN 
    ProductPurchases p2 ON p1.user_id = p2.user_id AND p1.product_id < p2.product_id
JOIN 
    ProductInfo info1 ON p1.product_id = info1.product_id
JOIN 
    ProductInfo info2 ON p2.product_id = info2.product_id
GROUP BY 
    p1.product_id, 
    p2.product_id, 
    info1.category, 
    info2.category
HAVING 
    COUNT(DISTINCT p1.user_id) >= 3
ORDER BY 
    customer_count DESC,
    product1_id ASC,
    product2_id ASC;

```

## 5. Python (Pandas)

```python
import pandas as pd

def find_product_recommendation_pairs(product_purchases: pd.DataFrame, product_info: pd.DataFrame) -> pd.DataFrame:
    # Prepare individual info dataframes for cleaner merging
    p1_info = product_info[['product_id', 'category']].rename(columns={'product_id': 'product1_id', 'category': 'product1_category'})
    p2_info = product_info[['product_id', 'category']].rename(columns={'product_id': 'product2_id', 'category': 'product2_category'})
    
    # Self-join to find pairs of products purchased by the same user
    pairs = pd.merge(product_purchases, product_purchases, on='user_id')
    
    # Filter out duplicate and reflective pairs (ensure product1_id < product2_id)
    pairs = pairs[pairs['product_id_x'] < pairs['product_id_y']]
    pairs = pairs.rename(columns={'product_id_x': 'product1_id', 'product_id_y': 'product2_id'})
    
    # Group by the product pairs and calculate unique customer counts
    grouped = pairs.groupby(['product1_id', 'product2_id'])['user_id'].nunique().reset_index()
    grouped = grouped.rename(columns={'user_id': 'customer_count'})
    
    # Filter out pairs that don't have at least 3 distinct customers
    filtered_pairs = grouped[grouped['customer_count'] >= 3]
    
    # Merge with product info to add categories for both products
    res = pd.merge(filtered_pairs, p1_info, on='product1_id')
    res = pd.merge(res, p2_info, on='product2_id')
    
    # Reorder columns as requested
    res = res[['product1_id', 'product2_id', 'product1_category', 'product2_category', 'customer_count']]
    
    # Sort by customer_count DESC, product1_id ASC, product2_id ASC
    res = res.sort_values(
        by=['customer_count', 'product1_id', 'product2_id'], 
        ascending=[False, True, True]
    ).reset_index(drop=True)
    
    return res

```
